NEW FEATURES

VERSION 4.1: WHAT CHANGED
- Admin dashboard rows now use an Edit button before showing update/delete controls.
- Bookings: Edit reveals status update controls. Bookings are not hard-deleted because they are rental history.
- Fleet inventory: Edit reveals Update and Delete for the selected transmission variant.
- Customers: Edit reveals Update and Delete. Customer deletion is still blocked when booking history exists.
- Payments: Edit reveals Update and Delete.
- Support messages:
  - Reply opens a reply box.
  - Edit reveals message status Update and Delete.
  - Sending a reply marks the message as Replied.
  - The reply is shown in the customer's dashboard Support inbox.
- Contact messages sent while logged in are linked to that user account.
- Older contact messages are linked to an account by matching the message email to the user's account email.

CUSTOMER DASHBOARD
